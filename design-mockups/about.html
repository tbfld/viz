How it's made

Draft — placeholder text below reflects what's actually true of the site as of this build; edit freely once the real credits are settled.

This site runs on Quartz, built from notes in Obsidian, hosted on GitHub Pages. Typefaces, tools, and image practice are credited below rather than on a separate colophon page.

Typefaces

  • Headings and interface labels — Gorton Digital Heavy, self-hosted. Noncommercial use only; cleared for this strictly noncommercial site. No italic/oblique master exists — tags use a browser-synthesized oblique.
  • Body text — Bitter (variable, with italic), self-hosted.

Tools & stack

  • Written in Obsidian.
  • Built with Quartz 4, run locally from an editable copy rather than as an npm dependency.
  • Deployed via GitHub Actions on every push, to GitHub Pages — no manual build step, so posting works from iOS without a Mac in the loop.

Images
