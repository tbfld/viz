# Design mockups

Static, standalone HTML/CSS mockups for the site redesign. Deliberately
**outside** `content/` so Quartz never builds these as pages — open the
.html files directly in a browser to review.

Fonts referenced here (`../quartz/static/fonts/`) are the same self-hosted
files the real site will use once a design is approved and ported into
`quartz/static/css/`.

Status: in progress, iterating with Claude.
