This project began as a critical analysis of [Edward Tufte](https://en.wikipedia.org/wiki/Edward_Tufte)’s work, but that negative framing was never very satisfying. In the decade+ since I began working on it project in earnest, 

it’s undergone several transformations.

This project has a straightforward question at its heart: What do ‘facts’ look like? The answer, of course, is they don’t look like anything at all — or, put differently, we can make them look like whatever we want.

## How it's made

*Draft — the text below reflects what's actually true of the site as of this build; edit freely once the real credits are settled.*

### Typefaces

- Headings and interface labels — **Gorton Digital Heavy**, self-hosted. Noncommercial use only; cleared for this strictly noncommercial site. No italic/oblique master exists — tags use a browser-synthesized oblique.
- Body text — **Bitter** (variable, with italic), self-hosted.

### Tools & stack

- Written in **Obsidian**.
- Built with **Quartz 4**, run locally from an editable copy rather than as an npm dependency.
- Deployed via **GitHub Actions** on every push, to **GitHub Pages** — no manual build step, so posting works from iOS without a Mac in the loop.

### Images

Most posts here are illustrated. Unless a caption says otherwise, images are used as part of an artistic transformation — reworked, recontextualized, or paired with text in ways distinct from their original use — rather than republished as-is. Specific credits and sources are noted in individual post captions where relevant.
